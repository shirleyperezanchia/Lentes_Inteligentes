
# Lentes Inteligentes para Personas con Discapacidad Visual

## Descripción del proyecto

Proyecto Integrador del curso Paradigmas de Programación de la Universidad Nacional de Costa Rica.

El proyecto consiste en el desarrollo de un prototipo de lentes inteligentes basado en ESP32, orientado a brindar asistencia complementaria a personas con discapacidad visual mediante la detección de obstáculos, el reconocimiento de determinados objetos y la generación de alertas.

## Objetivo general

Desarrollar un prototipo de lentes inteligentes basado en ESP32 que permita detectar obstáculos y reconocer determinados objetos del entorno, incorporando alertas auditivas y vibratorias y un sistema de registro de detecciones en un servidor local.

## Funcionalidades previstas

- Detección de obstáculos mediante un sensor ultrasónico.
- Medición de distancias y generación de alertas según la proximidad y el movimiento relativo de los obstáculos.
- Reconocimiento de determinadas categorías de objetos mediante ESP32-CAM.
- Alertas mediante sonidos y vibraciones.
- Comunicación de objetos reconocidos mediante mensajes de voz en un dispositivo móvil.
- Registro de detecciones en un servidor local.
- Alimentación portátil mediante batería.

## Tecnologías y componentes previstos

- ESP32.
- ESP32-CAM.
- Sensor ultrasónico.
- Componentes de alerta sonora y vibratoria.
- Batería recargable.
- Comunicación mediante red local.
- Servidor y base de datos local.

Las herramientas de programación, los paradigmas y las tecnologías de software se definirán durante el desarrollo del proyecto.
